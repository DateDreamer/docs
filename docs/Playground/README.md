# Playground

Try out DateDreamer's components and options interactively. Adjust the controls and watch the calendar update in real time — the generated configuration below shows exactly what options object was used, ready to copy into your own code.

## Notes

- Date presets (`minDate`, `maxDate`, predefined ranges) are computed relative to today, so the playground always renders with live, in-bounds dates.
- The playground runs against the published bundle loaded from [unpkg](https://unpkg.com/datedreamer), so only released features are available here.
- For the full list of options, see [Options](/Options/).
